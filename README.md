# 🎵 Musoffed

A sleek, privacy-focused offline music player web application. Organizes and plays your local music library directly inside the browser with zero external network dependencies.

## ✨ Highlights

- **100% Client-Side**: No audio is ever uploaded to a remote server.
- **Persistent Library**: Imported tracks and folders are saved in browser storage (`IndexedDB`) across reloads.
- **20 Genre Categories**: Auto-categorizes imported directory tracks by genre.
- **Full Player Dock**: Shuffle, repeat, seek scrubbing, volume control, and favorites.
- **Zero Dependencies**: Pure HTML5, CSS3, and modern Vanilla JavaScript.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern web browser (or run with VS Code's **Live Server**).
3. Click **Add files** or **Import folder** to load your music.

## 🛠 Tech Stack

- HTML5 Audio & Semantic Layout
- Pure CSS (Responsive Grid, Custom Variables, Dark UI)
- Vanilla JS (IndexedDB API, Web Audio, URL Object Blobs)
